01 让版本跟着项目走
识别 Node、Python 和 Go 项目配置，按项目要求安装、切换环境。
02 网络与工具，一处打理
配置 npm / pip 镜像与 Go 模块代理，管理包管理器和 Go 开发工具。
03 发布前，先心里有数
npm 发布支持打包演练、账号切换、公开包选项和 OTP 错误提示。
04 更新，按你的节奏
桌面启动时检查一次，随时手动检查；更新包通过 SHA256 校验后再安装。

02 / 命令行
